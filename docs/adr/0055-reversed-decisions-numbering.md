# 0055. (D43) 뒤집은 결정의 파일 번호는 0043~0054, 결정일이 없는 것은 기록일

- 상태: 채택 (2026-11-28) · 사용자 결정(표준 하네스 형식 표준화)

같은 날 `docs/DECISIONS.md`를 `docs/adr/`로 옮길 때 뒤집은 결정 Xn을 01nn에 두었다. 표준은 「다음 번호」로 이어 붙이는 것이라, X1~X12를 0043~0054(Xn = 0042+n)로 다시 매겼다. 문서 간 참조는 제목 앞 괄호의 Dn·Xn으로 하므로 그대로 통한다. 이 결정부터 파일 번호(0055~)와 D 번호(D43~)는 같지 않다. 결정일이 적혀 있지 않던 50건은 상태 줄에 git 기준 기록일을 「기록 YYYY-MM-DD」로 적었다 — 결정한 날과 다를 수 있다.
