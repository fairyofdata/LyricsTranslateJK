# 설계 결정 기록

확정된 결정과 근거. 결정 하나에 파일 하나(`NNNN-영문-제목.md`). 뒤집은 결정은 지우지 않고 상태를 「뒤집음」으로 바꿔 아래 「뒤집은 결정」 표로 옮긴다 — 되돌릴 때 근거가 필요하다.

설계의 다섯 원칙은 [PLAN](../PLAN.md) 1.3이 정본이다. 아래 결정은 모두 그 원칙의 구현이다.

번호는 유지한다. 파일 번호는 결정 하나에 하나씩 이어 붙인다: 현행 결정 D1~D42는 파일 0001~0042(Dn = 00nn), 뒤집은 결정 X1~X12는 0043~0054(Xn = 0042+n). 제목 앞 괄호가 옛 번호이고, 문서 간 참조는 계속 Dn·Xn으로 한다. 새 결정은 다음 파일 번호(0055~)와 다음 D 번호(D43~)를 함께 받는다 — 그때부터 파일 번호와 D 번호는 같지 않다. 뜻이 바뀐 결정은 본문을 고친다.
