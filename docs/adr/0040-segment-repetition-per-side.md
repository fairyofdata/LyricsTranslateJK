# 0040. (D40) 분절 반복은 원문 쪽과 번안 쪽을 따로 본다

- 상태: 채택

`repeat_of`는 **양쪽이 모두 반복일 때만** 쓰고 그때만 `unique_pairs`에서 뺀다. 한쪽만 반복이면 `src_repeat_of` / `tgt_repeat_of`로 적고 분석 대상에 **남긴다.**

**이유:** 처음에는 원문이 후렴을 반복하면 번안도 반복한다고 가정했다. 코퍼스가 그걸 양방향으로 깼다.

- **번안 쪽만 반복** — `s003`은 원문 2절 후렴이 `世界が`로 바뀌는데 번안은 1절의 `계절이`를 그대로 쓴다. `s004`·`s005`도 같다. 번안가가 라인 충실도를 버리고 **기억하기 쉬움**을 택한 것이고, 버릴 자료가 아니라 측정 대상이다
- **원문 쪽만 반복** — `s005`는 후크 `ギンギラギン`이 같은데 번안이 `이 시간 홀로`/`이 세월 가도`로 갈린다. **같은 원문 구간에 두 번안이 찍힌 쌍**이므로 거리 함수 모수에 가장 값나가는 자료다

양쪽 반복만 뺐더니 `s005`의 분석 대상이 분절 32개 중 17개로 남았다 — 원문 쪽만 반복인 것을 함께 뺐다면 5개였다.
