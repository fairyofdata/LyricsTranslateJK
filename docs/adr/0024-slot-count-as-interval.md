# 0024. (D24) 음원 없는 경로의 슬롯 수는 점이 아니라 구간이다

- 상태: 채택 · 기록 2026-11-15(git 기준 — 결정일은 기록에 없음)

받침이 같은 음표 안에서 실현되는지 뒤 음표로 넘어가는지는 선율이 정하는 일이고 텍스트로는 알 수 없다. 템플릿 슬롯은 `slot_min`·`slot_max`를 갖고, 하드 제약은 "후보의 슬롯 점유가 구간 안에 있는가"로 정의된다.

**충족률과 평균 구간 폭을 언제나 함께 보고한다.** 구간을 넓히면 충족률이 공짜로 오르기 때문이다. 목표는 "좁은 구간으로 높은 포함률"이고, 그것이 템플릿 경로가 쓸 만한지의 판정이다(SPEC 6.3 가, 분기점 0).

**이유:** D4로 음원을 선택 층으로 내리면서 생긴 불확실성을 단일값으로 가장하면, 모르는 것을 아는 척하는 X4의 실수가 되돌아온다. 불확실성을 구간으로 드러내고 그 폭을 함께 보고하는 것이 정직한 처리다.
