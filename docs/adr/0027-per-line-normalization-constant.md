# 0027. (D27) 발음 점수의 정규화 상수는 라인별이고, 무관한 실제 라인에서 추정한다

- 상태: 채택

`phon_score = 1 − 누적 자질 거리 / C(라인)`. `C`는 목표 언어의 **무관한 실제 라인** `M`개(기본 100, 다른 곡, 슬롯 수 구간 일치)와의 평균 거리다.

**이유:** (가) 균등 무작위 모라열은 실제 가사보다 멀다 — 실제 텍스트에는 빈도 구조가 있어 흔한 모라끼리 몰린다. 무작위열로 추정하면 `C`가 과대평가되어 모든 점수가 높게 뜬다. (나) 길이를 맞추지 않으면 거리가 삽입·삭제 비용에 지배되어 `C`가 "무관한 소리"가 아니라 "길이가 틀림"을 잰다. (다) 전역 상수는 음운이 특이한 라인의 점수를 치우치게 하고, 라인을 가로질러 합산하는 초부피 비교의 축을 라인마다 다른 뜻으로 만든다.

`C`의 분포를 공개한다. 분산이 작으면 전역 상수로 되돌려도 되고, 그 판단의 근거가 된다.
